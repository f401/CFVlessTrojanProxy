参数

?ed=2560早期数据长度，把首包塞进 WS 握手，省 1 个 RTT
?proto=vless / trojan / both（订阅用）
?rg=强制地区出口，如 rg=de、rg=nl（数据面用）
?ip=入口标签，仅用于 RTT 统计，不影响功能
?k=页面口令（配置了 pageKey 才生效）

行为说明

  • 默认出口：直连，出口是 Cloudflare 边缘 IP；连不上（Cloudflare 托管站点如 X）才降级到 proxyip。
  • 地区出口：路径带 &rg=xx 时跳过直连，直接用该国 proxyip，出口即该国 IP。
  • 切换策略：{{policy}}，能通就一直用，不主动跳 IP。
  • 鉴权：UUID（VLESS）/ 密码（Trojan），两者共用同一套统计。
path 里的 ed=2560 不要去掉；换客户端只改订阅链接即可。
