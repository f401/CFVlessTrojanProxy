# 控制面重构与技术债验收

本轮以仓库 7.434 为基线，本地重构，不部署。当前变更覆盖控制面、页面、领域状态所有权、并发快照和验证体系；代理协议、持久化格式、评分公式保持兼容。

7.435–7.438 又做了四件事（都属于可维护性，不碰运行时行为）：每位成员变量写清含义并加棘轮门禁；
`READY` 并进 `POOL_MEMORY`、零字段的 `QualityProbe` 改成自由函数 `qualityOf()`；
`routes/logs.ts` 并进 `routes/health.ts` 以守住 124 个文件的预算；
地区面板的数据装配抽成 route 层读模型 `route/panel-rows.ts`，`routes/region-panel.ts` 不再逐个认识事实表。

## 已落实

| 债务 | 变更 | 验收 |
|---|---|---|
| 地区路由混合展示与业务 | 路由负责查询、缓存、POST；views/regions.ts 负责只读页面模型和渲染 | 原 JSON 键、分页和 POST 路径兼容，页面契约测试 |
| PageView 无状态转发 | 删除包装类，订阅路由直接调用纯渲染函数 | 控制页与统计页仍有行为测试 |

| 翻页保存丢掉页外选择 | 服务端补全页外已选项；浏览器保存有期限的本用户差量草稿 | 原版失败、修改版通过；真实浏览器跨页与 POST 验证 |
| 页面口令在跳转时丢失 | 表单、分页、JSON、探测重载及保存跳转保留口令 | 大小写敏感及含空格符号的页面契约 |
| 探测按钮按固定 8 秒恢复 | 请求结束后解除在途状态，成功后展示 60 秒冷却 | 浏览器检查请求在途与结果回填 |
| 站点投影污染共享行缓存 | decorate 返回新对象，基础行保持不变 | 站点 RTT 正确且缓存行不变的行为断言 |
| 大型评分测试难维护 | 320 个独立块按领域提取到六个套件；统一入口保留顺序及共享夹具 | 全套评分回归；不在模块导入时运行案例 |
| npm test 可能测试旧包 | npm test 与 test:ui 先 bundle 再 mk_test；页面契约接入 preflight | 完整本地门禁 |
| 文档口径漂移 | 修正 isolate、无状态视图和预算入口说明 | 文档、架构、状态归属门禁 |

| 页面视觉与手机操作不统一 | 公共设计变量、导航、可滚动宽表、焦点、状态播报、密码折叠 | 真实 Edge 桌面与 390px 手机视口截图和交互 |

密码折叠只降低屏幕直接暴露，不构成新的权限控制；页面仍沿用现有鉴权。草稿只保存选择差量和表单字段，不保存页面口令，按用户路径隔离，30 分钟到期；存储被浏览器禁止时表单仍可使用。

## 扩展约定

新增传输沿用 ProbeTransport 与注册表，新增用户路径沿用 RouteTable，策略跨层调用沿用类型化 HOOK。新增页面先确定只读输入模型，再增加渲染及契约。已有框架足够承载当前扩展，不能通过叠加无状态 Service/Manager 包装来表示解耦。

AppState 和 S 已移除。54 个活跃字段归属领域类，删除无人读取的 eg4Top；入口仅保留 site/colo。历史与本轮共 90 个已迁出字段由门禁防止回潮；请求参数、预算随调用传递。新增缓存必须记录容量、TTL、失效条件及所有者；不能为了减少一个全局名字而强行合并六张事实表。

## 预算与性能边界

请求入口目前仍使用只计数而不拒绝的 BudgetedIO.unlimited，cron 使用有限账本。这是已有补救链兼容行为，本轮只修正文档，不把累计拨号次数错误地当成并发数；并发、超时和平台上限仍分别受原有机制约束。进一步收紧请求额度必须先证明真实补救链兼容，再单独变更。

本轮不宣称吞吐、延迟或 Worker CPU 获得提升。页面新增资源会增加 bundle，完整门禁和页面测试只能证明本地兼容。平台 CPU、真实流量与长期选路收益仍需部署后的成对观测，不能以单次仿真作结论。

本轮真实浏览器验收使用 Edge，覆盖桌面及 390px 手机视口；尚未实测 Firefox 或物理手机。20 节点延迟场景以种子 1–8、每种子 8 小时成对运行，原版与修改版输出一致，代价比中位数均为 1.29；这只说明该场景没有选路回退，不代表线上性能提升。

## 验证入口

- node tools/preflight.mjs：完整本地门禁，含页面契约，不部署。
- npm test：重建后执行现有套件及页面契约。
- node tools/ui-browser.mjs：使用本机 Edge 的无头 CDP；只访问本地夹具服务，输出截图和 JSON 记录。可通过 EDGE_PATH 指定浏览器。
- node test/ui.mjs --root TARGET：对原版、修改版、回滚版使用相同 45 节点夹具。
- node tools/sim-colo.mjs 1：四个独立实例共享节点名称，验证统计与种子对象隔离；替代依赖已删除统计接口的历史实验，不用于性能结论。

本地命令输出保存在 .tmp-sim，测试和门禁随代码提交。验证不包含部署。

## 仍需独立评估

不把预算保护、TTL、有界集合或协议兼容逻辑当作冗余删除。跨 isolate 事实传播的长期收益、免费计划高负载下的额度耗尽，以及线上冷启动 CPU 需要真实流量观测。测试入口剩余的历史顺序夹具继续保留；领域套件已分离，但完全隔离所有老夹具应逐组建立行为证据后再推进。

## 领域所有权与并发修复

| 领域 | 所有者 | 约束 |
|---|---|---|
| 节点样本与引用 | NodeMemory | 排名代数、在途引用零值删除；统计不跨 isolate |
| 选路与池 | SelectionMemory、PoolMemory、SeedStore | 切换字段一并更新；池代际采用与两阶段持久化分开 |
| 计量 | PendingLedger、UsageMemory、MeterClientState、KvWriteState | 新建实例不写进默认账本；DO 总账口径不变 |
| 入口与错误 | EntryMemory、ErrorMemory | 快照成功只确认本轮增量；写入在途的新字节、同时间戳 RTT 和新错误全部保留 |
| 判定记忆 | Policy、ShadowTable、TfbBook、VtSyncLedger、FactSwitches、RelayDemand | 保留原规则；需求表插入即裁剪；加载成功后才置 ready |
| 展示 | RegionPageCache | 类型化基础行、单槽 JSON、30 秒 TTL；移除无用全量指纹 |

DNS、DO 用量缓存、入口负缓存、站点排行和影子观测的容量淘汰改为保留近期有效行。CF HTTP 在途守卫满载时跳过新增探测，不清除未完成任务身份。排名前提变化时的显式失效仍然保留。

同一并发快照输入在原版产生 up=0/down=0、新用户=0、RTT=0、错误为空；修改版保留 up=5/down=7、新用户 up=9、RTT hits=1、错误 during、脏字节=21，两轮累计守恒。test/state.mjs 可用 --bundle 指向原版测试包复现。

新增状态门禁反例覆盖聚合根、S 门面、入口业务字段、转发 getter 和成员丢失，历史注释不会误报。新测试运行于独立进程，历史评分套件的顺序夹具继续保留，避免无证据改写已有行为。
